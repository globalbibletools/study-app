# UI

## Overview
Presentation layer for the application, organizing feature screens, common components, settings dialogs, reader panels, and study tools across dedicated subdirectories.

## Subdirectories & Boundaries
- about: [./about/README.md](./about/README.md) - Application metadata, version information, credits, and localized markdown documents.
- backup_restore: [./backup_restore/README.md](./backup_restore/README.md) - Database snapshot backup, restore, export, and import tools.
- common: [./common/README.md](./common/README.md) - Shared cross-feature widgets, translation pickers, download dialogs, and icons.
- download: [./download/README.md](./download/README.md) - Resource manager for downloading and deleting Bible texts, audio packs, and gloss files.
- home: [./home/README.md](./home/README.md) - Primary study workspace coordinating navigation bars, original language panels, audio players, and reading plans.
- search: [./search/README.md](./search/README.md) - Scripture search interface with on-screen Hebrew and Greek virtual keyboards.
- settings: [./settings/README.md](./settings/README.md) - User configuration options for language, theme, font size, and text layouts.
