# Panel Area

## Overview
Coordinates and hosts the split Scripture viewing panels and reading overlays, providing `BiblePanelArea` [panel_area.dart:BiblePanelArea] to manage the top Hebrew/Greek panel, bottom Bible translation panel, reading session overlays, and inter-panel synchronization.

## Subdirectories & Boundaries
- bible_panel: [./bible_panel/README.md](./bible_panel/README.md) - Secondary Scripture panel displaying translation text with infinite scroll and verse synchronization.
- hebrew_greek_panel: [./hebrew_greek_panel/README.md](./hebrew_greek_panel/README.md) - Primary original language panel displaying Hebrew and Greek texts with morphological annotations and audio highlighting.
- common: [./common/README.md](./common/README.md) - Common panel overlays, celebrations, calendar views, and infinite scroll widgets.
