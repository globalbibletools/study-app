# Assets

## Overview
Houses static assets, bundled dictionaries, fonts, graphic assets, localization copy, and SQLite database migration schemas packaged with the Flutter application.

## Subdirectories & Boundaries
- schemas: [Schemas](./schemas/README.md) - SQLite database DDL schema definitions, version migration scripts (v1 to v3), and initial seed data for reading plans.
- databases: Bundled static SQLite databases providing biblical Hebrew, Greek, and lexical reference data.
- fonts: Bundled SBL Hebrew and Greek typeface files and corresponding end-user license agreements.
- images: Static graphics and application branding icons.
- l10n: Localized markdown assets used in application info and about screens.
