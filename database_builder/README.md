# database_builder

## Overview
A sample command-line application with an entrypoint in `bin/`, library code
in `lib/`, and example unit test in `test/`.

This package provides offline SQLite database construction pipelines for Scripture translations, interlinear glosses, biblical original languages (Hebrew, Aramaic, and Greek), semantic lexicons, and audio synchronization timestamps.

## Subdirectories & Boundaries
- [lib](./lib/README.md): Core database builders, SQL schema definitions, text normalization utilities, and command-line compilation scripts.
